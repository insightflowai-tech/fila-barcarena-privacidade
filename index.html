Política de Privacidade - Fila Barcarena Última atualização: 06 de maio de 2026 Esta Política de Privacidade descreve como o app Fila Barcarena, desenvolvido por Venistech, acessa, utiliza, armazena e protege dados tratados durante o uso do aplicativo. 1. Quem somos Desenvolvedor: Venistech Contato para privacidade: venistech@gmail.com 2. Dados tratados pelo app O app pode tratar os seguintes dados, de acordo com o uso feito pelo usuário: Link da fila informado manualmente ou lido por QR code 4 primeiros dígitos do CPF informados para localizar a senha no sistema externo da fila Número da senha, última senha chamada, previsão de atendimento e horário estimado Dados retornados pelo sistema externo da fila, como nome do motorista, placa do veículo e nome da fila, quando disponíveis Preferências locais do usuário, como opções de som, vibração e alertas 3. Como os dados são usados Os dados são usados para: Consultar a fila informada pelo usuário Monitorar a evolução da senha Exibir previsões e status do atendimento Emitir alertas quando a vez estiver próxima ou chegar Manter configurações e preferências locais do app 4. Compartilhamento de dados O app não usa redes de anúncios e não vende dados pessoais. Para funcionar, o app envia as informações de consulta ao serviço externo da fila indicado pelo próprio usuário ou associado ao QR code lido. Esse envio é necessário para retornar os dados do atendimento e do monitoramento. 5. Armazenamento local O app pode armazenar localmente no aparelho algumas preferências e dados temporários de sessão para melhorar a experiência de uso e permitir a continuidade do monitoramento. O histórico salvo localmente não guarda o link completo da fila. 6. Segurança Sempre que possível, a comunicação com os servidores é realizada com criptografia em trânsito por HTTPS. O app também foi configurado para bloquear tráfego em texto claro. 7. Retenção e exclusão de dados Os dados locais podem ser removidos quando o usuário encerra o monitoramento, limpa os dados do aplicativo no Android ou desinstala o app. Dados tratados por sistemas externos de fila seguem as políticas e regras do respectivo operador desse sistema. 8. Permissões utilizadas Câmera: para leitura de QR code Notificações: para alertas da fila Vibração: para alertas configurados pelo usuário Internet: para consultar os dados da fila 9. Contato Se você tiver qualquer dúvida, solicitação de privacidade ou pedido relacionado a dados tratados pelo app, entre em contato pelo e-mail venistech@gmail.com.
