Politica de Privacidade - Fila Barcarena

Ultima atualizacao: 05 de maio de 2026

Esta Politica de Privacidade descreve como o app Fila Barcarena, desenvolvido por Insight Flow AI, acessa, utiliza, armazena e protege dados tratados durante o uso do aplicativo.

1. Quem somos

Desenvolvedor: Insight Flow AI

Contato para privacidade: insightflowai.tech@gmail.com

2. Dados tratados pelo app

O app pode tratar os seguintes dados, de acordo com o uso feito pelo usuario:

  • Link da fila informado manualmente ou lido por QR code
  • 4 primeiros digitos do CPF informados para localizar a senha no sistema externo da fila
  • Numero da senha, ultima senha chamada, previsao de atendimento e horario estimado
  • Dados retornados pelo sistema externo da fila, como nome do motorista, placa do veiculo e nome da fila, quando disponiveis
  • Preferencias locais do usuario, como opcoes de som, vibracao e alertas

3. Como os dados sao usados

Os dados sao usados para:

  • Consultar a fila informada pelo usuario
  • Monitorar a evolucao da senha
  • Exibir previsoes e status do atendimento
  • Emitir alertas quando a vez estiver proxima ou chegar
  • Manter configuracoes e preferencias locais do app

4. Compartilhamento de dados

O app nao usa redes de anuncios e nao vende dados pessoais.

Para funcionar, o app envia as informacoes de consulta ao servico externo da fila indicado pelo proprio usuario ou associado ao QR code lido. Esse envio e necessario para retornar os dados do atendimento e do monitoramento.

5. Armazenamento local

O app pode armazenar localmente no aparelho algumas preferencias e dados temporarios de sessao para melhorar a experiencia de uso e permitir a continuidade do monitoramento.

O historico salvo localmente nao guarda o link completo da fila.

6. Seguranca

Sempre que possivel, a comunicacao com os servidores e realizada com criptografia em transito por HTTPS. O app tambem foi configurado para bloquear trafego em texto claro.

7. Retencao e exclusao de dados

Os dados locais podem ser removidos quando o usuario encerra o monitoramento, limpa os dados do aplicativo no Android ou desinstala o app.

Dados tratados por sistemas externos de fila seguem as politicas e regras do respectivo operador desse sistema.

8. Permissoes utilizadas

  • Camera: para leitura de QR code
  • Notificacoes: para alertas da fila
  • Vibracao: para alertas configurados pelo usuario
  • Internet: para consultar os dados da fila
